# 数据结构

## 堆

可以用[]完成数据存储，他的特性是，一个完全二叉树，保证他的root一定大于他的左右，因此可以利用他的结构特性完成排序任务O（logn）

```python
import heapq
arr = []
for num in numbers:
	heapq.heappush(arr,num)#默认是最小堆
heapq.heappop(arr,num)#扔出最小值
#进阶用法
for num in numbers:
	heapq.heappush(arr,(num,index))#存入元组，默认按照第一个元素大小排序
heapq.heappop(arr)[1]#扔出num最小的，index元素
	
```

## 栈

同样可以用[]完成数据存储，他的特性是先入先出，用于匹配

```
arr = []
arr.append(2)  # equivalent to arr.push(2) in JavaScript
arr.append(5)  # equivalent to arr.push(5) in JavaScript
print(arr.pop()) #5



arr.insert(index,value)#在指定位置插入value
arr.pop(index)#删除指定位置的东西
```
